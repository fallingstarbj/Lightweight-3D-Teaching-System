# 轻量化三维示教系统 使用说明书

*Lightweight 3D Teaching System*

## 应用简介

**轻量化三维示教系统**（*Lightweight 3D Teaching System*）是一款基于 Electron 的 Windows 桌面应用，面向课堂教学与三维资源管理，支持模型查看、结构标注、动画编辑、状态机等功能。

软件需**激活后使用**。首次安装可开启 **7 天全功能试用**（每台电脑一次），或输入购买获得的正式激活码。无需账号登录。

> **说明**：软件激活与数据包激活相互独立，使用同一机器码，但激活码不同。

支持两种浏览模式：

| 模式      | 说明                                  |
| ------- | ----------------------------------- |
| **本地**  | 浏览电脑上的任意文件夹                         |
| **数据包** | 安装并激活 `.3dam-pack` 离线数据包，浏览其中的模型与贴图 |

### 主要功能

- **教学资源管理** — 本地文件夹与数据包双模式浏览，安装/激活/导出 `.3dam-pack` 数据包
- **模型查看** — 多格式 3D 预览，自动缩略图，标准视角、截图、面框、网格、炸开、测距、透明、剖面等
- **结构标注** — 标注集合管理，支持标记点、箭头、图文标注，可拖动调整位置
- **动画编辑** — FBX 片段播放；部件多阶段关键帧动画，支持位移/旋转录制与数值编辑
- **教学状态** — 将部件位置、旋转、缩放、可见性与材质保存为命名快照，课堂一键切换
- **部件结构树** — 显示/隐藏、重命名零部件；选中部件名称显示在视口顶部
- **UV 查看器** — 按 `V` 打开独立窗口，查看 UV 布局与贴图平铺（滚轮缩放、拖拽平移）
- **材质编辑** — 基础色与法线贴图，多材质槽位独立编辑与保存（数据包模型可持久化）
- **关联文档** — 数据包模型可上传 PDF，预览时分屏显示三维模型与文档
- **贴图 / 音频 / 视频 / PDF** — 数据包内可包含独立文档与媒体资产，双击全屏预览、播放或阅读
- **搜索与排序** — 按文件名搜索，按名称 / 大小 / 修改时间 / 类型排序
- **界面偏好** — 网格/列表视图、缩略图大小、强调色与背景色自动保存

## 安装与启动

### 便携版（推荐给最终用户）

无需安装，复制单个可执行文件即可运行：

1. 双击 `轻量化三维示教系统-1.0.0-Portable.exe` 启动
2. 启动时会显示加载界面：上方为**中文 / 英文双语**软件名称，下方为功能简介；加载完成后进入主界面
3. **首次启动**会进入软件激活界面：可点击 **「开始 7 天试用」**，或粘贴正式激活码
4. 激活成功后默认进入「数据包」模式；可切换到「本地」浏览自己的文件夹
5. 若已购买数据包，点击 **「安装数据包」** 导入 `.3dam-pack` 文件

#### 激活软件

软件授权与数据包授权分开管理：

1. 激活界面显示本机 **机器码**，请将其提供给销售方以获取正式激活码
2. 首次使用可点击 **「开始 7 天试用」**（每台电脑仅一次）
3. 试用或正式授权到期后，需输入新的正式激活码才能继续使用
4. 工具栏版本号旁会显示 **试用剩余天数** 或 **授权剩余天数**（永久授权显示「已授权」）

> **分发说明**：最终用户只需 exe 文件、软件激活码，以及内容方提供的数据包与数据包激活码，无需安装 Node.js 或其他依赖。

### 开发模式

```bash
cd 3d-asset-manager
npm install
npm run dev
```

修改主进程或 preload 代码后，需**完全重启** `npm run dev` 才能生效。

### 构建便携版

```bash
# 主程序
npm run pack

# 数据包制作工具（内容方专用）
npm run pack:builder

# 同时构建两者
npm run pack:all
```

产物位于 `release/` 目录。

> **注意**：若提示 exe 被占用，请先关闭正在运行的应用实例再重新打包。

## 浏览模式

工具栏提供 **本地** / **数据包** 两种模式：

### 本地模式

浏览电脑上的任意文件夹，操作与常规文件管理器类似：

1. 点击 **「选择文件夹」** 选择项目根目录
2. 左侧子目录列表、面包屑导航切换目录
3. 单击选中资产，双击或点击「预览」打开全屏查看
4. 可 **「在资源管理器中打开」** 定位原文件

在根目录使用搜索时，会在整个目录树中按文件名查找。

### 数据包模式

浏览已安装并激活的数据包内容：

1. 根目录显示各数据包的**文件夹**（名称与数据包一致）
2. **双击**文件夹进入，查看其中的模型与贴图
3. 顶部面包屑或 **「上级」** 按钮返回数据包列表
4. 在根目录搜索时，会在**全部已激活数据包**中跨包查找

#### 安装数据包

1. 点击工具栏 **「安装数据包」**
2. 选择 `.3dam-pack` 文件
3. 若数据包需要激活，安装后会弹出激活窗口

#### 激活数据包

每个数据包可绑定到当前电脑，支持永久或限时激活：

1. 安装后若未激活，会提示输入**数据包激活码**
2. 激活界面显示**机器码**，需将其提供给内容方以获取激活码
3. 也可通过工具栏 **「管理」** 进入数据包管理页，对未激活的包点击 **「激活」**

#### 导出数据包（含教学数据）

内容方在本机完成标注、部件动画、教学状态、材质与 FBX 播放偏好后，可将教学数据一并写入数据包：

1. 工具栏 **「管理」** 进入数据包管理页，或选中数据包文件夹后在右侧面板操作
2. 点击 **「导出（含教学数据）」**
3. 确认摘要（含标注 / 部件动画 / 教学状态 / 材质 / FBX 偏好的模型数量）后选择保存路径
4. 导出的 `.3dam-pack` 保留原 **packId** 与各模型 **ID**，可分发给终端用户安装

若本机教学数据曾被修改，可通过 **「恢复包内教学数据」** 将安装时保存的包内默认数据写回本机（会覆盖对应模型的本地编辑）。

#### 删除数据包

- **删除整个文件夹**：在根目录单击选中数据包文件夹，右侧面板点击 **「删除数据包」**
- **删除单个模型**：进入数据包文件夹，选中模型后右侧面板点击 **「删除模型」**
- **管理页卸载**：工具栏 **「管理」** → 对应数据包 **「卸载」**

删除数据包会卸载其中的全部资产；本地标注、材质与动画编辑数据会保留在 `%APPDATA%` 中。

## 数据包制作工具（内容方）

内容方使用独立的 **数据包制作工具** 打包模型与贴图，并为用户生成**数据包激活码**与**软件激活码**。

### 启动方式

```bash
# 开发模式
npm run builder

# 或使用打包后的便携版
轻量化三维示教系统-数据包制作工具-1.0.0-Portable.exe
```

## 内容方工作流（含教学数据）

推荐流程：**制作工具打初版包 → 主程序安装编辑 → 主程序导出含教学数据的包 → 分发给用户**。

| 步骤       | 工具             | 说明                                        |
| -------- | -------------- | ----------------------------------------- |
| 1. 打裸包   | 数据包制作工具        | 导入模型/贴图，导出初版 `.3dam-pack` 与激活码            |
| 2. 安装    | 主程序            | 在本机安装并激活该数据包                              |
| 3. 编辑    | 主程序预览          | 完成标注、部件动画、教学状态、材质覆盖、FBX 默认片段与自动播放         |
| 4. 导出    | 主程序管理页 / 文件夹详情 | **「导出（含教学数据）」**，生成可分发的新包                  |
| 5. 生成激活码 | **数据包制作工具**    | 读取导出的 `.3dam-pack` 或输入 packId，按用户机器码生成激活码 |
| 6. 分发    | —              | 用户安装新包后输入激活码即可使用                          |

> 制作工具仅用于冷启动打包；**含教学数据请一律在主程序导出**。旧版无 `edits/` 的数据包安装行为与以前一致。

### 制作流程

1. 填写 **数据包名称** 与 **版本号**
2. 点击 **「导入模型」** 添加 FBX、GLB、OBJ、STL 等模型文件
3. 点击 **「导入贴图」** 添加 PNG、JPG 等贴图文件（可选）
4. 列表中可勾选资产后点击 **「删除选中」** 移除误导入的文件
5. 点击 **「导出 .3dam-pack」** 保存数据包（至少需一个模型或贴图）
6. 导出成功后，填写用户的 **机器码**，选择授权类型，生成 **数据包激活码** 发给用户

**为主程序导出的包生成激活码：**

1. 切换到 **「二、生成数据包激活码」**
2. 点击 **「从 .3dam-pack 读取」**，选择主程序导出的文件（packId 会自动识别）
3. 输入用户机器码并生成激活码（也可手动粘贴 packId）

> 含教学数据请回主程序导出；激活码一律在制作工具中生成。

**生成软件正式激活码：**

1. 切换到 **「三、生成软件激活码」**
2. 在区块二中填写用户 **机器码** 与授权类型（限时 / 永久）
3. 点击 **「生成软件激活码」** 并复制发给用户（用于主程序激活界面，与数据包激活码不可混用）

> 命令行 `npm run license:generate` 仍可生成软件激活码，功能与制作工具第三区块相同。

### 数据包格式说明

- 模型在包内以 **AES-256-GCM 加密**存储（`.3dam` 格式），贴图为明文
- 数据包含 manifest 签名，防止清单被篡改
- 激活码与机器码绑定，用于控制谁能在本机使用该数据包
- 可选 **`edits/`** 目录（`editsVersion: 1`）携带教学数据：标注、部件动画、教学状态（含贴图）、材质覆盖（含贴图）、FBX 播放偏好

安装时：若本机尚无对应编辑数据则写入；若已有本地编辑则默认不覆盖。卸载数据包后教学编辑仍保留在 `asset-library` 中。

## 3D 模型预览

双击支持的模型文件，进入全屏 3D 预览。

### 预览界面布局

```
┌─────────────────────────────────────────────────────────────┐
│  标题栏 · 关闭 (Esc)                                         │
├──────────┬──────────────────────────────────┬───────────────┤
│          │  选中部件名称（视口顶部居中）      │               │
│  部件    │                                  │   右侧标签页   │
│  结构树  │         3D 视口                 │  渲染/动画/…  │
│          │                                  │               │
│          ├──────────────────────────────────┤               │
│          │  底部工具栏（视角/截图/标注/…）    │               │
└──────────┴──────────────────────────────────┴───────────────┘
```

### 视口操作

| 操作  | 鼠标                 | 触摸     |
| --- | ------------------ | ------ |
| 旋转  | 左键拖动               | 单指滑动   |
| 缩放  | 滚轮                 | 双指捏合   |
| 平移  | 右键拖动（或中键）          | 双指并排滑动 |
| 关闭  | 点击右上角关闭按钮，或按 `Esc` | 同左     |

底部工具栏可切换 **鼠标 / 触摸** 输入模式。

### 左侧部件结构树

- 列出模型全部零部件（组与网格），可点击选中
- 点击眼睛图标切换部件**显示 / 隐藏**
- **双击**部件名称可**重命名**（仅影响界面显示名，不修改模型文件）
- 再次点击已选中的部件可取消选中
- 选中部件后，视口顶部居中显示当前部件名称

### 底部工具栏

| 工具              | 说明                              |
| --------------- | ------------------------------- |
| 俯视图 / 正视图 / 左视图 | 切换到标准正交视角（基于 Three.js Y 轴朝上坐标系） |
| 恢复视角            | 回到打开模型时的初始视角                    |
| 截图              | 截取视口区域保存到桌面                     |
| 正常 / 面框         | 切换实体面+边线显示（面框模式便于观察结构）          |
| 网格              | 显示 / 隐藏底部参考网格                   |
| 标注              | 选择要显示的标注集合（数据包模型）               |
| 教学状态            | 快速切换已保存的教学状态（数据包模型）             |
| 炸开模型            | 将各零部件沿法线方向散开                    |
| 测距              | 在模型表面测量两点距离                     |
| 透明              | 点击部件使其半透明，便于观察内部                |
| 剖面              | 沿 X/Y/Z 轴剖切模型                   |
| 鼠标 / 触摸         | 切换输入模式                          |

### 右侧标签页

| 标签     | 功能               | 适用范围  |
| ------ | ---------------- | ----- |
| **渲染** | 预览设置 + 材质编辑      | 所有模型  |
| **动画** | FBX 动画 + 部件关键帧动画 | 所有模型  |
| **状态** | 教学状态编辑           | 数据包模型 |
| **文档** | 上传与切换关联 PDF      | 数据包模型 |
| **标注** | 结构标注集合与标记        | 数据包模型 |

### 预览设置

在 **「渲染」** 标签中可调节：

- 背景颜色
- 光照方位（水平角度）
- 环境光强度
- 主光强度

修改后自动保存，并影响后续模型缩略图的渲染效果。

### 材质编辑

在 **「渲染」** 标签进入编辑模式后：

1. 在左侧部件树或模型上点击零部件
2. 若该零部件有**多个材质**，会显示材质槽位列表，可切换编辑
3. 也可直接点击模型上对应材质的面，自动选中该槽位
4. 支持调节基础色、透明度，以及 **基础色贴图**、**法线贴图**
5. 勾选 **「材质贴图」** 后可为各槽位指定贴图文件
6. 修改会自动保存；每个材质槽位（`零部件 + 材质序号`）独立存储

导入模型时，若材质带有贴图，底色会自动设为白色，避免贴图偏色。

> 数据包模型与本地模型均可预览；**材质编辑的保存**仅对数据包中的模型生效。

### FBX 动画

若 FBX 文件包含动画片段，预览窗口底部会显示动画控制条：

- 支持选择动画片段、播放 / 暂停
- **数据包模型**会记住默认片段与是否自动播放，并随数据包导出/安装同步
- 本地文件夹中的模型默认不自动播放

### 部件动画

在 **「动画」** 标签中，可为模型零部件录制**位移与旋转**关键帧动画。动画由多个**阶段**组成，阶段首尾相接，每阶段可独立命名。

**阶段管理：**

- 点击 **「新建阶段」** 添加阶段，**双击**阶段名称可重命名（如「打开盖子」「转动轴」）
- 点击阶段名称或 **「编辑」** 切换到该阶段进行编辑
- 点击 **「播放」** 仅播放当前阶段；**「播放全部」** 按顺序播放所有阶段
- 底部时间轴上的阶段色块可点击切换阶段
- 可调整当前阶段时长（秒）

**录制关键帧：**

1. 在左侧选中要动画的零部件
2. 拖动视口中的变换手柄，或在侧栏输入位移/旋转数值
3. 移动时间轴到目标时刻，点击 **「在当前时间添加关键帧」**
4. 每次添加关键帧后自动保存

**变换手柄快捷键（动画编辑模式下）：**

| 按键   | 功能          |
| ---- | ----------- |
| `W`  | 切换为位移模式     |
| `E`  | 切换为旋转模式     |
| `空格` | 播放 / 暂停部件动画 |

### 教学状态

在 **「状态」** 标签中，可将当前场景保存为**命名快照**（离散教学步骤），适合拆装步骤、故障模式、不同贴图方案等**一键切换**的场景。

每个状态可包含：

- 部件的**位置、旋转、缩放**与**可见性**
- **材质与贴图**快照（每状态可独立一套方案）
- 结构树节点的显示/隐藏

**与部件动画的区别：**

| 能力   | 部件动画         | 教学状态          |
| ---- | ------------ | ------------- |
| 心智模型 | 时间轴、关键帧、多阶段  | 「第几步 / 叫什么名字」 |
| 切换方式 | 播放、拖动时间、点击阶段 | 点击状态名、底栏状态切换器 |
| 材质   | 不纳入轨道        | 每状态可含材质快照     |
| 缩放   | 暂不支持         | 支持            |
| 适用场景 | 连续转动、往复运动    | 拆装步骤、静态构型对比   |

应用教学状态时会暂停部件动画预览；连续演示段仍用部件动画或 FBX 动画，步骤切换用教学状态。

**操作步骤：**

1. 切换到 **「状态」** 标签，输入名称后点击 **「新建状态」**
2. 选中状态进入编辑，在场景中调整部件位置、旋转、缩放与可见性（可切换到 **「渲染」** 标签编辑材质）
3. 使用 `W` / `E` 切换位移/旋转手柄，拖动手柄或输入数值
4. 在对应状态卡片上点击 **「保存」**，将当前模型与材质写入该状态
5. 课堂演示时，在预览底栏 **「教学状态」** 菜单中切换，或在侧栏点击 **「预览」** 查看已保存状态
6. 可将某一状态 **「设为默认」**，下次打开模型时自动应用

教学状态数据存放：

```
%APPDATA%\3d-asset-manager\asset-library\teaching-states\<模型ID>.json
```

贴图保存在同目录下的 `textures/` 子文件夹中。

### 关联文档

在 **「文档」** 标签中，可为数据包模型上传关联 PDF：

1. 点击 **「上传 PDF」** 选择文件
2. 在列表中点击文档名称，预览区将**分屏显示**：左侧三维模型，右侧 PDF 阅读
3. 可删除不再需要的文档

文档文件保存在 `asset-library/model-documents/` 目录下。

### UV 查看器

选中带有 UV 数据的部件后，按 **`V`** 打开独立 UV 查看器窗口：

- 显示该部件的 UV 线框与贴图预览
- 支持 UV 超出 0–1 范围的**四方连续贴图**平铺显示
- **滚轮**以鼠标位置为中心缩放
- **拖拽**平移视图
- 工具栏提供 `+` / `−` 缩放与 **「适应」** 重置视图
- 底部显示 UV 范围（如 `U -1.20~3.50 · V 0.00~2.10`）

### 大型模型说明

- 超大 FBX 首次加载可能较慢，预览窗口会显示加载进度
- **STL** 文件仅含几何体，显示为单色或顶点色，不支持贴图、UV 与动画
  - 加载时默认将文件中的 **+X 轴** 作为朝上方向，并自动对齐到 Three.js 的 Y 轴朝上坐标系
  - **预览与缩略图**使用同一套朝向规则
  - 若升级软件后缩略图仍显示旧朝向，请**完全退出并重启应用**，系统会按新规则重新生成缩略图
- 预览**默认保留原始面数**；超过 **100 万面** 时将提示是否减面（减面后约 50 万面以内）
- 缩略图生成时会对超大模型适当减面以提升速度
- 若出现黑屏，请确认文件未损坏，或尝试导出为 GLB 后重试
- 柜体等共面较多的模型若出现贴图闪烁，应用已优化深度缓冲与单面渲染；仍异常时可参考「常见问题 → 模型贴图闪烁」

## 结构标注

结构标注用于在 3D 模型上标注教学要点，适用于**数据包中的模型**。支持多个**标注集合**，同时仅显示一个集合。

### 标注类型

| 类型  | 说明           |
| --- | ------------ |
| 标记点 | 圆点标记，可附名称与说明 |
| 箭头  | 两点之间的箭头标注    |
| 图文  | 带图片的图文说明标注   |

### 操作步骤

1. 双击打开数据包中的模型，进入 3D 预览
2. 切换到 **「标注」** 标签
3. 输入名称后点击 **「新建集合」** 创建标注集合
4. 选中集合，点击 **「添加标记」**，在模型表面点击放置位置
5. 选择标注类型，填写名称与说明，点击 **「保存标记」**
6. 创建后可**拖动**标记调整位置
7. 底部工具栏 **「标注」** 按钮可快速切换显示的集合
8. 可编辑或删除已有标记与集合

### 标注数据存放

标注默认保存在本机 `asset-library`，内容方导出含教学数据包时会写入 `edits/` 并随包分发：

```
%APPDATA%\3d-asset-manager\asset-library\markers\<模型ID>.json
```

卸载数据包后标注数据仍保留；删除单个模型时会一并清除该模型的标注。终端用户安装含 `edits/` 的包后会自动获得包内标注。

```
%APPDATA%\3d-asset-manager\
```

## 常见问题

### 软件激活失败

- 确认使用的是**软件激活码**，而非数据包激活码（两者不可混用）
- 确认激活码与当前界面显示的机器码匹配
- 若提示「本机已使用过试用」，需购买正式授权
- 试用或限时授权到期后，需联系销售方获取新的正式激活码

### 数据包安装失败

- 确认文件扩展名为 `.3dam-pack`
- 若提示「已安装」：同一数据包（相同 packId）现在可直接重新安装，将自动覆盖旧版本并尽量保留有效激活信息
- 若文件夹列表中看不到某包但仍无法安装：打开工具栏 **「管理」**，查看未激活数据包并卸载

### 数据包激活失败

- 确认激活码与当前机器码匹配
- 确认激活码与所安装的数据包对应（不同数据包激活码不可混用）
- 限时激活码过期后需联系内容方续期

### 数据包列表为空

- 确认数据包已成功安装且**已激活**
- 未激活的数据包不会显示在文件夹列表中，可在 **「管理」** 页查看并激活

### 找不到数据包内的模型

- 确认已进入对应的数据包文件夹（根目录只显示文件夹，不直接显示资产）
- 使用搜索框可跨包按文件名查找

### 模型缩略图显示占位图标

- 通常为缩略图生成失败（文件损坏、格式不受支持、或解析超时）
- 同一文件在同一次运行中失败后不会反复重试；重启应用后可再试
- 加密模型（`.3dam`）需应用正确识别原始格式，请确保使用最新版本
- 大型 FBX 首次生成较慢，请稍候；若长期失败，见下方「FBX 缩略图或预览失败」

### STL 缩略图朝向与预览不一致

- 确认已使用最新版本并**完全退出后重启**应用（旧版缩略图缓存可能仍保留错误朝向）
- 软件升级后会自动失效旧缓存并按 **+X 轴朝上** 重新生成
- 若单个文件仍异常，可进入 3D 预览后保存截图，或删除 `%APPDATA%\3d-asset-manager\thumbnails\` 后重新浏览

### 模型预览黑屏或贴图显示异常

- 确认文件未损坏
- OBJ 需确保 MTL 及贴图路径正确；FBX 贴图通常在模型同目录或 `模型名.fbm/` 子目录
- FBX 版本过新时可导出为 GLB 重试
- 超大模型请耐心等待加载提示完成
- 若 UV 查看器贴图正常但 3D 预览发黑，常见原因：
  - 材质底色为黑色（已与贴图相乘导致全黑），应用会自动修正
  - AO / 金属度贴图在 UV 超出 0–1 时未平铺，应用会自动设为 Repeat 模式
  - 贴图文件路径错误或加载失败，请检查贴图是否与模型在同一目录

### 模型贴图闪烁（噪点/花屏感）

柜体、设备面板等含大量**几乎共面**的薄板时，容易出现深度冲突（z-fighting），旋转视角时贴图像在「闪烁」。

应用已做以下缓解：收紧相机近远平面、启用对数深度缓冲、不透明材质默认单面渲染。

若仍有轻微闪烁，建议在建模软件中：
- 合并或删除完全重叠的重复面
- 给贴花/铭牌相对底板留出极小厚度或偏移
- 重新导出为 GLB / FBX 7.4+ 后再预览

### FBX 缩略图或预览失败

部分由 3ds Max 导出的 FBX（旧版本、复杂材质/动画）可能无法被 Three.js 正确解析。可尝试：
- 在 Blender 或 3ds Max 中重新导出为 **FBX 7.4+ 二进制**，或直接导出为 **GLB**
- 确认外置贴图与 FBX 位于同一目录（或 `模型名.fbm` 文件夹）
- 若缩略图一直转圈后变为占位图标，属解析失败或超时，可按上述方式重导模型后再试

### 便携版 exe 无法生成（文件被锁定）

先关闭正在运行的轻量化三维示教系统，再执行 `npm run pack`。

### Electron 安装失败（开发环境）

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
node node_modules/electron/install.js
```

或重新执行 `npm install`。

### 清理应用数据

删除 `%APPDATA%\3d-asset-manager\` 可清除软件激活、试用记录、已安装数据包、缩略图、标注与编辑数据。删除后需重新激活软件并重新安装、激活数据包。
